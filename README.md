# Controle de Ponto em Java

Projeto simples desenvolvido em Java para praticar lógica de programação, orientação a objetos e regras de negócio.

## Objetivo

Simular um sistema básico de controle de ponto de funcionários, analisando horário de entrada, horário de saída e quantidade de horas trabalhadas.

## Funcionalidades

O sistema permite:

- cadastrar dados de funcionários
- calcular horas trabalhadas
- identificar jornada completa
- identificar hora extra
- identificar saída antecipada
- identificar atraso
- exibir um resumo da situação de cada funcionário

## Estrutura do projeto

### Funcionario.java

Classe responsável por representar o funcionário e executar as regras de negócio.

Possui:

- nome
- horário de entrada
- horário de saída
- cálculo de horas trabalhadas
- análise da jornada
- verificação de atraso
- exibição do resumo

### Main.java

Classe responsável por iniciar o programa e criar exemplos de funcionários com diferentes situações.

Foram utilizados exemplos de:

- funcionário com hora extra
- funcionário que saiu mais cedo
- funcionário que chegou atrasado
